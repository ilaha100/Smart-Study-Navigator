# Smart Study Navigator

Final project for the Building AI course

## Summary
Smart Study Navigator, tələbələrin akademik materiallarını analiz edərək onları idarə oluna bilən gündəlik öyrənmə planlarına çevirən süni intellekt əsaslı bələdçidir.

## Background
Tələbələr tez-tez həcmli kurs materialları və tapşırıqlar qarşısında vaxt idarəetməsi və prioritetləşdirmə problemləri ilə üzləşirlər. Bu layihəni yaratmağa motivasiyam tələbələrin akademik performansını artırmaq və vaxtlarını daha səmərəli idarə etmələrinə kömək etməkdir.

## How it works
Sistem yüklənmiş sənədləri (PDF, qeydlər) emal edir, əsas anlayışları çıxarır və istifadəçinin qalan vaxtına uyğunlaşdırılmış, addım-addım fərdiləşdirilmiş təlim planı yaradır.

## Data sources
Kurs materialları (dərsliklərin PDF faylları, sillabus) və tələbənin cari bilik səviyyəsi.

## Challenges
Müxtəlif fayl formatlarının oxunması və AI modelinin akademik terminologiyanı düzgün kontekstdə təfsir etməsi.
